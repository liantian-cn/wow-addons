# 骰子账本（RollLedger）

将整个 RollLedger 文件夹放入客户端 Interface/AddOns，重新登录并开启友方姓名板。Interface 固定为 16001。

显示统计 1044（需求次数）除以 932（打本次数），保留一位小数。原宏的 1043 用于需求率，插件不显示需求率，因此不读取该项。颜色使用未舍入值：小于3绿色，3至5黄色，大于5红色。无有效数据不显示。

只处理其他友方玩家，无需组队。姓名板出现时自动排队，一次查询一人，至少间隔3秒；5秒超时，失败退避60秒。成就窗口打开时暂停新查询。缓存按GUID账号共享，成功获取后24小时失效；重载不清空。不会自动开启姓名板或切换目标。

## 命令

- `/rollledger`：帮助。
- `/rollledger font 12`：字号8–32。
- `/rollledger offset 6 0`：水平、垂直偏移各−100至100。
- `/rollledger reset`：恢复字号12、偏移6/0，不清除缓存。

## 游戏内验收

本插件尚未在 Forever 客户端实测。Interface 号不能证明API兼容。必须确认客户端提供 C_NamePlate.GetNamePlateForUnit、姓名板增删事件、C_Timer.NewTimer，以及带玩家GUID的 INSPECT_ACHIEVEMENT_READY 事件，并允许 SetAchievementComparisonUnit 接收 nameplate 单位。

1. 开启友方姓名板，观察未组队玩家，等待排队查询；用原宏核对数字。
2. 检查3和5为黄色；无数据、打本次数为零时隐藏。
3. 移出视野、关闭姓名板、让姓名板框架复用，确认不残留其他人的数字。
4. 重载和切换账号内角色，检查缓存；过期后应隐藏旧值并重新查询。
5. 打开成就窗口、查询失败及超时后，检查暂停和退避行为。
6. 调整字号、偏移并重载；输入越界参数应仅提示帮助。

若姓名板持续不显示但原宏可读取统计，需要排查Forever对姓名板单位查询和完成事件的支持，不应视为已完成兼容验证。插件没有退回仅目标或鼠标指向查询。其他插件同时操作全局成就比较接口也可能干扰查询。
